# Code of Conduct

This project follows the [Contributor Covenant][covenant], version 2.1.

Participants are expected to be respectful, assume good faith, give and
receive constructive feedback, and avoid harassment, discrimination,
threats, doxxing and publication of private information. Maintainers may
remove contributions that violate these expectations or create avoidable
hardware or security risk.

Report conduct concerns privately through the project maintainer or the
repository's private GitHub communication channels. Do not include private
keys, exploit material or hardware dumps in a report.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
