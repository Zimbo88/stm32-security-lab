# STM32 Security Lab v1.0.0

## Summary

Version 1.0.0 is the initial public source baseline for STM32 Security Lab.
The tag exists as a historical reference point and is superseded by v1.0.1 for
the complete hardware-validated secure-update evidence.

The v1.0.0 baseline introduced the secure-boot research direction, the EXP045
Stage-0 bootloader line, signed image tooling, release policies, HIL framework
foundation, and the BSD 3-Clause project license.

## Scope

- STM32F429 secure-boot research baseline.
- SHA-512 payload integrity verification.
- Ed25519 manifest authentication.
- Manifest, vector-table, and address-range validation.
- Rollback-floor policy demonstration.
- Early redundant metadata and slot-management groundwork.
- Host-side signing, verification, and release artifact tooling.
- Initial hardware-in-the-loop framework.

## Later Superseding Evidence

The hardware-validated dual-slot secure-update path, UART binary protocol,
`stm32ctl`, A-to-B/B-to-A update campaign, and current release-readiness
documentation are part of the later v1.0.1 release state.

## Important Limitations

This is a research platform and has not undergone third-party certification.
It does not claim certified resistance to physical attacks or suitability for
unreviewed production deployment.
