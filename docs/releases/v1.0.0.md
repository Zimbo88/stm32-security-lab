# STM32 Security Lab v1.0.0

## Summary

Version 1.0.0 is the first public research release of STM32 Security Lab.

The release provides a hardware-validated secure-boot baseline for the
STM32F429 family, together with host tooling, authenticated image preparation,
redundant metadata, slot policy, recovery support, and automated
hardware-in-the-loop testing.

## Highlights

- SHA-512 payload integrity verification;
- Ed25519 image authentication;
- manifest and address-range validation;
- redundant boot metadata;
- A/B signed application slots;
- rollback-aware boot policy;
- controlled update and recovery workflow;
- deterministic host-side verification;
- real-hardware HIL test automation;
- flash backup, restoration, and read-back verification.

## Validation

The final HIL campaign reported:

- 15 passed tests;
- 0 failed tests;
- 0 errors;
- 0 skipped tests;
- verified restoration of the bootloader, both metadata copies, and both
  application slots.

The secure-update v2 hardware completion run on 2026-07-27 additionally
reported:

- successful authenticated A-to-B update to Slot B version 3;
- successful authenticated B-to-A update to Slot A version 4;
- SHA-512 and Ed25519 executed before each application jump;
- rollback rejection for lower and same image versions;
- fail-closed rejection of corrupted manifest, target, signature and payload
  cases;
- safe fallback after abort and reset during `WRITING`;
- UART parser recovery for bad CRC, skipped sequence, partial frame and random
  input;
- byte-for-byte flash readback for both positive update targets;
- unchanged RDP0 Option Bytes.

Physical power removal and visual LED observations are not claimed by the
curated v1.0.0 evidence set.

## Research purpose

This release establishes a reproducible baseline for later defensive research
into STM32 protection state, malformed firmware loading, fault injection,
glitch response, debug accessibility, and memory-state changes.

## Important limitations

This is a research platform and has not undergone third-party certification.
It does not claim certified resistance to physical attacks or suitability for
unreviewed production deployment.
